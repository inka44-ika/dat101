  2. Same as question #1. How ever the answer should now be different. Discuss the behavior of part 2, What happens when the wake-up time is not 7 and what happens when it is exactly 7?

    3. [På oppgave 2 legger vi til else. Hvis klokka er 7, printer programmet det som står etter if. Hvis klokka ikke er 7, går den videre til else og printer det som står der.]

  3. Discuss the behavior of part 3, what happens when wake time is less than 7 or greater than 8?

    4. [Nå har vi lagt til else if og, mellom if og else. Den kan an bruke for å sjekke enda flere alternativer. Så hvis if er 7 og else er 8, kan vi bruke else if for å sjekke andre alternativer.]

  4. Discuss the behavior for part 4, what happens if the number is exactly 0, is zero positive or negative?
Nummeret er konstant "5". Systemet sjekker om "if(>0)" & "else if(<0)" påstandene er sanne og vil derfor enten printe ut "the number is negative/positive". Om nummeret er eksakt 0, vil det printe ut "the number is zero", siden vi la til en "else" funksjon i tillegg, med den påstanden.
